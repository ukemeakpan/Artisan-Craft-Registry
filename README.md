# Artisan Craft Registry

A blockchain-based system for authenticating handmade crafts and tracking their provenance. This smart contract enables artisans to register their creations while providing quality verification through certified inspectors.

## Features

- Craft item registration with detailed metadata
- Quality verification by certified inspectors
- Artisan portfolio management
- Provenance tracking for handmade items

## Usage

Deploy the contract and use the public functions to register crafts and verify quality.
